呉音/漢音・慣用音・連濁・連声と同音異義語の打ち分け〈一例：資料その７〉


（１）役に立っている例

［音］観音 → かんのん：かんおん → 漢音
［元］元祖 → がんそ：げんそ → 元素
［着］上着 → うわぎ：うわき → 浮気
［着］水着 → みずぎ：みずき → 水木
［工］工夫 → くふう：こうふ → 鉱夫/交付/公布/甲府/...
［下］下校 → げこう：かこう → 下降/火口
［下］下山 → げざん：かざん → 火山
［解］解毒 → げどく：かいどく → 解読/貝毒/買い得/...
［西］東西 → とうざい：とうさい → 搭載/...：とうせい → 統制/...
［済］経済 → けいざい：けいさい → 掲載/茎菜
［早］早速 → さっそく：そうそく → 総則
［三］三郎 → さぶろう：さんろう → 三浪
［山］火山 → かざん：かさん → 加算
［山］鉱山 → こうざん：こうさん → 降参/公算/恒産/興産
［算］演算 → えんざん：えんさん → 塩酸
［詩］詩歌 → しいか：しか → 歯科/市価/...
［色］色覚 → しきかく：しょっかく → 触覚/触角/食客
［世］世界 → せかい：せいかい → 正解/政界/盛会/...（cf. 「せい」は 漢音，世紀＝せいき）
［生］平生 → へいぜい：へいせい → 平成/平静/...
［雑］雑巾 → ぞうきん：ざっきん → 雑菌
［登］登山 → とざん：とうざん → 当山；とうさん → 倒産/父さん
［名］戒名 → かいみょう：かいめい → 改名/解明
［楽］文楽 → ぶんらく：ぶんがく → 文学
［和］和尚 → おしょう/わじょう：かじょう → 過剰（cf. 「か(くゎ)」は 漢音）

（２）役に立っていない例

［応］反応 → はんのう → 飯能；はんおう → ◎
［音］母音 → ぼいん → 拇印；ぼおん → ◎
［街］街道 → かいどう → 海棠/会堂/海道/会同：がいどう → ◎
［角］方角 → ほうがく → 邦楽/法学；ほうかく → ◎
［殺］相殺 → そうさい → 総裁/...；そうさつ → ◎
［殺］殺生 → せっしょう → 折衝/摂政；さっせい → ◎
［産］安産 → あんざん → 暗算；あんさん → ○（cf. 原産/減産 → げんさん）
［出］出納 → すいとう → 水筒/水稲/水痘/...；しゅつのう → ◎
［除］掃除 → そうじ → 相似/送辞/...；そうじょ → ◎
［土］土地 → とち → 栃/橡：どち → ◎
［納］出納 → すいとう → 水筒/水稲/水痘/...；しゅつのう → ◎
［富］富豪 → ふごう → 符号/符合/...；ふうごう → ◎（cf. 「ふう」は 漢音，富貴＝ふうき）
［露］披露 → ひろう → 疲労/拾う/...；ひろ → ○

（３）どちらともいえないもの

［音］子音 → しいん → 死因/試飲/...：しおん⇒師恩/紫苑/シオン/...
［甲］甲板 → かんぱん → 乾パン：こうはん⇒後半/公判/広範/...：かふはん → ※
［起］縁起 → えんぎ → 演技：えんき⇒延期/塩基
［亀］亀甲 → きっこう → 拮抗：きこう⇒機構/気候/気功/紀行/奇行/寄稿/帰港/...
［拠］証拠 → しょうこ → 翔子：しょうきょ⇒消去
［西］関西 → かんさい → 完済/簡裁/艦載/...：かんせい⇒完成/感性/歓声/官制/...
［山］開山 → かいざん → 改竄：かいさん⇒解散/海産/...
［参］見参 → けんざん → 剣山/検算；けんさん⇒研鑽：けさん⇒△
［参］新参 → しんざん → 深山/新山；しんさん⇒辛酸
［算］演算 → えんざん → 塩山/円山/猨山；えんさん⇒塩酸
［作］操作 → そうさ → 捜査/走査/層さ/沿うさ/...；そうさく⇒創作/捜索/...：そうそ → ※
［心］肝心 → かんじん → 閑人；かんしん⇒関心/感心/...：きもしん → ※
［心］信心 → しんじん → 新人：しんしん⇒心身/新進/...：しなしん → ※（cf. 信濃＝しなの）
［代］交代 → こうたい → 後退/抗体/...：こうだい → 後代/広大/工大/...：かうとい → ※
［渡］佐渡 → さど → サド：さと⇒差と/... /里：さ゜と゜→ ※
［杜］杜氏 → とうじ → 当時/冬至/答辞/湯治：とし → 都市/杜氏(人の名)：とうしい → ※
［道］神道 → しんとう → 新党/浸透/親等/震盪/...：しんどう → 振動/震動/神童/進藤/...
［頭］音頭 → おんど → 温度：おんとう⇒穏当：おんづ → ※
［徳］功徳 → くどく → 口説く：こうとく⇒高徳/...：くとく → ○
［配］勾配 → こうばい → 購買/紅梅/...：こうはい⇒後輩/荒廃/交配/...：くおはい → ※
［薬］薬缶 → やかん → 夜間：やっかん⇒約款：やくかん → ○
