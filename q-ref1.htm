【漢字＆かな】
　原則として漢字の読みをローマ字綴りにしたものの頭文字。ダウンロードは こちら から。

（１）基本法則〔名詞系〕

Ａ．漢字１文字を英小文字１文字に置き換える
　　例：私 → ｗ　職業 → ｓｇ　北海道 →ｈｋｄ　東京農大 → ｔｋｎｄ

　　　　新幹線 → しんＫ　高飛車 → たかＢ　下北沢 → しもＫ

　　　　引受会社 → ひうＧ　積立年金 → つたＮ　受取総額 → うとＳ　差引残高 → さひＺ　
　　　　売上伝票 → うあＤ　請負契約 → うおＫ　差込印刷 → さこＩ

（２）特殊記号を使った入力法

Ａ．慣用的に ひらがな／カタカナで表記するもの
　　１．ひらがなで表記するもの「＜」
　　　　例　ことわざ → ｋ＜
　　　　　　こんにゃく → ｋｎ＜
　　　　　　やまだたろう → ＹＴ＜
　　２．カタカナで表記するもの「＞」
　　　　例　ネズミ → ｎ＞
　　　　　　コンニャク→ ｋｎ＞
　　　　　　ヤマダタロウ → ＹＴ＞

Ｂ．繰り返しを「＋」で表す
　　１．「々」の代わりに
　　　　例　日々 → ひ＋（cf. ひび＝ひび/皹/...，ひひ＝ヒヒ）
　　　　　　いろいろ→ いろ＋（色々 → ｉ＋）
　　２．擬音語・擬態語で
　　　　例　しゃぶしゃぶ → ｓｈｂ＋/しゃぶ＋
　　　　　　ゴチャゴチャ → ｇｃｈ＋/ごちゃ＋
　　３．読みがな付き
　　　　例　出生（しゅっしょう）→ しゅっしょう＋/ｓｓ＋＞
　　　　　　理（ことわり）→ り＋/ことわり＋/ｋ＋＞

Ｃ．省略を表すもの
　　１．オンビキ活用型（＋拡張連打法）
　　　　例　いわゆる → いーーー　やっぱり → やーーー　ヨーグルト → よーーーー
　　２．ピリオドを使う方法〈コロン等でも可〉（※ ＩＭにより 使えない場合あり）
　　　　例　ホテル → ほ．（cf. ほてる ⇒ 火照る）
　　　　　　チラシ → ち．　メガネ → め．　デザイン → で．　
　　　　　　アナウンサー → あな．　アシスタント → あし．
　　　　　　チョコレート → ちょこ．　ヘルメット → へる．
　　　　　　ポイント → ぽ．　リハーサル → りは．　
　　３．連体詞・副詞などの省略「－（マイナス記号）」（※ＩＭにより使えない場合あり）
　　　　例　カッと → か－（cf. カット＝ｃｕｔ）
　　　　　　ちょっと →ｃ－　　並々ならぬ → ｎｎｎ－　　
　　　　　　待ちに待った → まち－/ＭＭ－　　知る人ぞ知る → しる－/ＳＳ－　
　　４．短文登録「＝」（※ＩＭにより使えない場合あり）
　　　　例　ありがとう。 → あり＝
　　　　　　ありがとうございます。 → ありご＝/ＡＧ＝
　　　　　　ありがとうございました。 → ありご＝＝/ＡＧ＝＝
　　　　　　あけましておめでとうございます。 → あけおめ＝/ＡＯＧ＝
　　５．略語など「：/＝」（※ＩＭにより使えない場合あり）
　　　　例　セブン → ７：　セブンイレブン → ７１１：

Ｄ．接続詞・副詞を「＿」で表す。（※読点も含めて）
　　例　つまり、→ つ＿（cf. つまり⇒詰まり）
　　　　したがって、→ した＿（cf. したがうて⇒従って）
