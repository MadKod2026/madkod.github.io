打ち言葉として使いたいハングル〈一例・資料その８〉


【使えそうなもの】

　科学 → クァハク（cf. かがく⇒化学/価額/下顎）
　韓国 → ハングク（cf. かんこく＝勧告）
　機械 → キゲ（cf. きかい⇒器械→ぐげ）
　牛乳 → ウユ
　銀河 → ウナ（cf. ぎんが⇒銀が）
　常識 → サンシク
　食堂 → シクタン（cf. しょくどう⇒食道）
　大学 → テハク
　単語 → タノ（cf. たんご⇒タンゴ）
　秘書 → ピソ（cf. ひしょ⇒避暑）
　疲労 → ピロ（cf. ひろう⇒拾う/披露）
　文学 → ムナク
　放棄 → ポギ（cf. ほうき⇒箒/ほうき）


【使えないもの】

　案内 → アンネ〈人の名前〉
　鉛筆 → ヨンピル＝容弼〈人の名前〉
　音楽 → ウマク＝上手く
　歌手 → カス＝粕/滓/貸す/科す/...
　学生 → ハクセン＝白線
　時間 → シガン＝志願
　写真 → サジン＝砂塵
　料理 → ヨリ＝寄り


【使えなくもない】

　感謝 → カムサ＝噛むさ（cf. かんしゃ＝官舎）
　技術 → キスル（cf. きする＝期する）
　時計 → シゲ〈人の名前：茂/繁〉
　食事 → シクサ≒しぐさ/仕草
　先生 → ソンセン（cf. せんせい＝宣誓/先制/...）
　朝鮮 → チョソン（cf. ちょうせん＝挑戦）
　道路 → トロ＝とろ
　美術 → ミスル＝ミスる/～見する
　毎日 → メイル≒メール

【アレンジして使いたいもの】

　火曜日 → かよひ/ぱよひ［ファヨイル］
　金曜日 → きんよひ/きむよひ［クミョイル＝クム＋ヨイル］
　手術 → すすつ/すずつ/すつつ［ススル］（すする＝啜る）
　水曜日 → すいよひ/すよひ［スヨイル］
　土曜日 → どよひ/とよひ［トヨイル］
　日曜日 → につよひ/にるよひ［イリョイル＝イル＋ヨイル］
　入学 → いふはく/いるはく［イッパク＝イプ＋ハク］（入る＝はいる/いる）
　文化 → むんふぁ/むふあ［ムヌァ＝ムン＋ファ］
　木曜日 → もくよひ/もきよひ［モギョイル＝モギ＋ヨイル］


【オマケ：日本語にもあるハングルっぽい言葉】

　垂水 → タルミ
　達磨 → ダルマ
　三位 → サンミ（＝サム＋イ）
　険悪 → ケンマク（＝ケム＋アク）
