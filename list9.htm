新別読み / 新連想２ストローク


【同音異義語対策になるもの】

　勘当 → かんたう，感動 → かんとゆ，
　機械 → きげ，器械 → ぐげ，（奇怪 → きくわい）
　時間 → ぢかん，字間 → なかん，次官 → にかみ，
　銭湯 → せにたう，［先頭，戦闘］
　船頭 → ふなとう，（先導 → せんたう，扇動 → せんとゆ）
　単語 → たんお（cf. たんご＝タンゴ）
　店舗 → てんほ（cf. てんぽ＝テンポ，補填＝ほてん）
　立地 → りるち（cf. りっち＝リッチ，建立＝こんりふ）

【省打鍵になるもの】

　案内 → あのい（cf. あない＝穴井）
　海抜 → はいはつ（cf. 上海のハイ＋音符・发）
　牛乳 → ぐぬ
　渋谷 → じふや（cf. 苦渋＝くじふ）〈…左右交互に打てる 兼 誤打鍵対応〉
　弁護士 → べごじ（cf. べんごし⇒弁護し，辺＝べ）〈…左右交互に打てる 兼 活用語尾対策〉
　打擲 → たあたく/だたく/だてき/ておてく（※「だ」は 慣用音）
　付属 → ぶそく〈…左右交互に打てる 兼 誤打鍵対応〉

【旧読み活用】

１．「～ou」→「～au」に
　Ａ．「かう」… 特にかな改対応で
　　　例：方向 → はうかう，校了 → かうれう，高校 → かうかう，
　　　（特例：方法 → はうはう/はうはふ）
　Ｂ．「さう」… 特に活用語尾対策として
　　　例：愛想 → あいさう，改装 → かいさう，
２．「けう」「せう」「てう」「へう」「えう」
　　　例：教育 → けういく，紹介 → せうかい，調整 → てうせい，表明 → へうめい，
　Ｃ．旧読み＋濁音＝「～ゆ」
　　　例：画像
　Ｄ．旧読み＋拗音＝「～お」
　　　例：強力 → かおりき，
　Ｅ．旧読み変則
　　　例：常識 → さおしく，食堂 → しくたわ，
　Ｘ．その他
　　　例：奇怪 → きくわい，

【拼音風】

・好⇒はお
　好評 → はおはお（※旧読みでは「かうひゃう」，こうひょう⇒高評/公表/...）
・大⇒たあ
　太陽 → たあやう（たいよう⇒大要/耐用/態様/...）
・道⇒たお
　食道 → しくたお（cf. しょくどう⇒食堂 → しくたわ）
　私道 → みたお，公道 → くおたお，
・了⇒らあ
　校了 → かうらあ（cf. かうれう⇒香料/高粱/稿料）
　了解 → らあかい（cf. りょうかい⇒領海/両会）
・老⇒らお
　老化 → らおけ（cf. ろうか⇒廊下/牢か/蝋か/...）
　老酒 → らおつ，老人 → らおにん，

【ハングル風】

・化⇒ぱ
　文化 → むぱ，
・河⇒あ
　運河 → うんあ/るんあ（銀河≒ウンア，阿＝あ，軍＝ぐん）
・学⇒はく
　科学 → わはく，化学 → ぱはく，
・国⇒くく
　韓国 → はんくく，
・若⇒なぎ
　若干 → なぎかん（cf. 老若男女＝らうにゃく～，諾＝だく），惹起 → なぎき，
・弱⇒てぎ
　弱冠 → てぎかん（cf. 溺＝でき）
・入⇒にる
　入学 → にるはく，入国 → にるくく，
・法⇒ぱ
　法規 → ぱき（cf. ほうき⇒箒/...，法被＝はっぴ，はつき⇒発揮）
・立⇒りる
　立地 → りるち，建立 → こんりる，確立 → かくりる，
